# Guia rápido — qual modelo usar no Bid&Ask

Use este guia apenas como orientação operacional. O custo interno do Itaú pode ser diferente do preço público.

## Regra principal

- **Sonnet 4.5**: padrão para começar. Use para entender fluxo, documentos, fontes, fatores de risco, preparar histórias e organizar registros.
- **Haiku 4.5**: use para tarefas mecânicas e consolidação quando a informação já estiver entendida: atualizar estado, resumir fontes, padronizar tabela, gerar checklist.
- **Opus 5.5**: escale somente para uma dúvida difícil e delimitada: conflito metodológico, cálculo complexo, contradição entre documentos ou revisão crítica de uma conclusão.
- **GPT-6 Astra Medium Thinking**: não deixe como padrão para tarefas simples. Use quando precisar de raciocínio mais profundo ou quando o desempenho justificar o custo interno.
- **DeepSeek / GLM / Qwen**: teste em tarefas verificáveis e de baixo risco. Se entregarem a mesma qualidade com menor custo interno, use-os para inventário, classificação, extração estruturada e checagens.

## Roteamento recomendado

1. Comece em **Sonnet 4.5**.
2. Se a tarefa for só organizar algo já entendido, troque para **Haiku 4.5**.
3. Se houver ambiguidade real, conflito de fontes ou cálculo difícil, recorte a pergunta e envie apenas o necessário para **Opus 5.5**.
4. Volte ao Sonnet para continuar o projeto.
5. Não use vários modelos ao mesmo tempo sem necessidade.
6. Não troque de modelo para compensar falta de acesso a arquivo, falta de dado ou falta de aprovação metodológica.

## Regra de economia

Modelo forte não substitui:
- fonte oficial;
- insumo ausente;
- regra aprovada;
- validação humana;
- ferramenta determinística.

Sempre prefira reduzir o escopo e fornecer só os trechos necessários antes de escalar o modelo.
