# 04 — Resolver dúvidas antes de escalar

**Modelo sugerido:** Claude Sonnet 4.6.

```text
Pode avançar para o próximo passo, mas com uma alteração:

Antes de levar D9-D12 para pessoas, tente resolver cada uma usando SOMENTE:
- fontes já catalogadas;
- arquivos/caminhos que já conhecemos;
- materiais já identificados no escopo desta investigação.

Não faça uma nova varredura ampla e não abra novas frentes.

Prioridade:
D12 → D9 → D11 → D10.

Para cada dúvida:

1. Reescreva a pergunta de forma objetiva.
2. Procure evidência somente nas fontes já conhecidas que possam respondê-la.
3. Classifique o resultado como:
   - RESPONDIDA POR EVIDÊNCIA;
   - PARCIALMENTE RESPONDIDA;
   - NÃO LOCALIZADA.
4. Cite exatamente a fonte utilizada.
5. Não transforme ausência de evidência em conclusão.

Se a dúvida NÃO puder ser resolvida documentalmente, prepare uma pergunta para validação humana contendo:
- pergunta exata;
- por que precisamos dela;
- qual decisão depende da resposta;
- qual perfil/área provavelmente conseguiria responder, sem inventar nome de responsável;
- qual evidência seria suficiente para encerrar a dúvida.

IMPORTANTE:
- não assuma que uma pessoa citada em material antigo continua sendo responsável;
- não transforme diagrama em metodologia oficial;
- não trate motores paralelos como divergência comprovada sem evidência;
- não trate uma situação descrita como demanda formal sem comprovação;
- não altere sistemas ou código.

ATUALIZAÇÃO DOS REGISTROS

Atualize o 02_PENDENCIAS.md com o novo status de D9-D12.

Atualize o 01_FLUXO_TECNICO.md somente se surgir informação técnica nova sustentada por evidência.

Não aumente o 00_CONTEXTO_GERAL.md com detalhes desta investigação, salvo se surgir uma mudança realmente estrutural.

ECONOMIA DE CONTEXTO

Esta sessão já está grande.

Ao terminar esta etapa:
1. informe quais dúvidas foram resolvidas;
2. liste somente as perguntas que realmente precisam de pessoas;
3. informe quais arquivos foram atualizados;
4. produza um HANDOFF CURTO para uma nova sessão contendo apenas:
   - objetivo atual;
   - arquivos que a próxima sessão deve ler primeiro;
   - dúvidas ainda abertas;
   - próximo passo exato.

Diga também se já é seguro encerrar esta sessão e continuar em uma nova sem perda relevante de contexto.

Não execute outro passo depois disso sem minha autorização.
```
